# LGDA Room Prototype

A single-device closed-loop biometric wellness room, from LGDA Technologies.

Your camera reads your state. The music and the screen light shift with it. The timeline log of both moving together is the proof.

- **Live:** https://lgda-technologies.github.io/lgda-room/
- **Put it in a space:** https://lgda-technologies.github.io/lgda-room/spaces.html — any device with a camera, nothing to install, thirty seconds to set up.
- All 27 tracks across 9 albums by Slator Blacc, playing free inside sessions.
- Nothing leaves your browser except a session you choose to save to History.
- Wellness music. Not a medical device; HRV values are estimates for research and educational use only.

The page is a single self-contained HTML file (`index.html`), exported from the verified prototype build (v18).
